# 🚗 CarWebSite

A full-stack ASP.NET Core MVC web application for browsing and showcasing cars. Built as a college team project, this app demonstrates clean architecture, Razor-based frontend views, and dynamic page rendering using C#.

## 📌 Features

- 🏁 Home page with car categories
- 📄 Detailed car pages with description and image
- 🎨 Razor Views for dynamic HTML rendering
- 🌐 Static assets served from `wwwroot`
- 🧠 MVC architecture with clean code separation
- 🚀 Fast startup and lightweight server logic

## 🛠️ Technologies Used

- ASP.NET Core MVC
- Razor Pages
- C# (.NET 6/7)
- HTML5 & CSS3
- JavaScript (basic interactivity)
- Visual Studio / Rider
